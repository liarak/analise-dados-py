# Análise de Dados com Python – Dados Climáticos (INMET)

## 📌 Descrição

Projeto de análise de dados climáticos utilizando Python, com foco em limpeza, exploração, visualização e interpretação estatística de séries temporais.

## 🛠️ Tecnologias utilizadas

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* SciPy
* Jupyter Notebook

## 📂 Estrutura do projeto

* data/ → dados climáticos do INMET (CSV)
* notebooks/ → análises em Jupyter Notebook

## 📊 O que foi feito

* Limpeza e tratamento de dados meteorológicos
* Análise exploratória das séries temporais
* Análise de tendência (média móvel, regressão e testes estatísticos)
* Análise de sazonalidade (boxplots mensais e testes não paramétricos)
* Extração e interpretação de insights

## 🚀 Objetivo

Demonstrar habilidades em análise de dados com Python aplicadas a um conjunto de dados real, com foco em estatística, séries temporais e comunicação dos resultados.
